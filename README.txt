WORLDCINEMA — WEBSITE STARTER
=============================

WHAT'S INCLUDED
- index.html: homepage
- discover.html: editorial film discovery catalogue
- film.html: reusable film profile page (cards open it with different film IDs)
- filmmakers.html: For Filmmakers page
- about.html: About and contact information
- styles.css and script.js: design and interactions

IMPORTANT
This is an early-development website, not a streaming service. The Discover page clearly labels its entries as editorial recommendations, not licensed films. Do not add playback buttons or claim distribution rights unless you have written permission from the relevant rights holder.

CONTACT
The contact section intentionally does not invent an email address. Before publishing, edit about.html and add a real contact email or another contact method you control.

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.
3. Click through the navigation and film cards.

HOW TO PUBLISH FOR FREE
A simple option is GitHub Pages:
1. Create a GitHub account if you don't have one.
2. Create a new public repository, e.g. worldcinema.
3. Upload all the files from this folder to the repository's root.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. GitHub will provide the published website address.

You can also use another static hosting provider. A custom domain usually costs money, so start with the free address.

EDITING
You can edit text directly in the HTML files using a plain text editor. Colours, spacing and layout are in styles.css. The sample film profile content is in script.js.
